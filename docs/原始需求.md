# 需求文档：Windows 网络流量监控日志归集系统

## 一、项目概述

请帮我编写一个 **PowerShell 脚本**，实现 Windows 系统网络流量的全面监控与日志归集。脚本需要完成以下工作：

1. **一次性初始化**：开启 Windows 所有相关审计策略和日志
2. **安装 Sysmon**：自动下载并安装 Sysmon（如果未安装）
3. **每日定时归集**：每天自动将过去 24 小时的所有网络相关日志归集为**一个文件**
4. **注册任务计划**：脚本首次运行时自动创建 Windows 任务计划，实现开机自启 + 每日定时执行
5. **随时可查**：归集后的日志为纯文本格式，可以直接用记事本/VS Code 打开，也可以发给 AI 分析

---

## 二、配置项（脚本顶部，用户可修改）

```powershell
# ============ 用户配置区 ============
$LogRootDir    = "D:\NetworkMonitor"        # 日志根目录（可修改）
$SysmonDir     = "C:\Sysmon"                # Sysmon 安装目录
$DailyRunTime  = "00:30"                    # 每天归集时间（24小时制）
$RetentionDays = 90                         # 日志保留天数（超过自动删除）
$ExportFormat  = "txt"                      # 导出格式：txt 或 csv
# ====================================
```

## 三、初始化阶段（仅首次运行执行）

脚本启动时检测是否已初始化，如果没有，执行以下操作：

### 3.1 开启 Windows 审计策略

```
需要开启的审计子类别：
- "Filtering Platform Connection"（成功）  → 记录每次网络连接（进程+目标IP+端口+方向）
- "Process Creation"（成功）              → 记录每次进程启动（进程路径+命令行参数）
```

### 3.2 开启 DNS Client 操作日志

```
日志通道：Microsoft-Windows-DNS-Client/Operational
操作：启用该日志通道
作用：记录每次 DNS 域名查询（域名+查询类型+解析结果）
```

### 3.3 启动 Sysmon

```
- 如果宿主机未启动Sysmon,则通过命令行启动。Sysmon配置目录：D:\AI\AI-Projects\NetLedger\config
```

### 3.4 创建日志目录结构

```
D:\NetworkMonitor\
├── logs\                    ← 每日归集日志存放目录
│   ├── 2026-07-27.txt
│   ├── 2026-07-26.txt
│   └── ...
├── scripts\                 ← 脚本自身存放目录
│   └── NetworkMonitor.ps1
├── sysmon\                  ← Sysmon 安装目录
│   ├── Sysmon64.exe
│   └── sysmon-config.xml
└── README.txt               ← 使用说明
```

### 3.5 注册 Windows 任务计划

```
任务名称：NetworkMonitor_DailyExport
触发器：
  - 触发器1：每天 $DailyRunTime 执行（默认 00:30）
  - 触发器2：系统启动后延迟 1 分钟执行（确保开机后也有当天数据）
操作：
  - 运行 powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File "$PSScriptRoot\NetworkMonitor.ps1" -Mode Export
条件：
  - 无论用户是否登录都运行
  - 使用 SYSTEM 账户运行（确保有权限读取安全日志）
  - 如果任务失败，每 10 分钟重试，最多重试 3 次
```

### 4.3 异常告警规则（写入统计汇总部分）

脚本需要自动检测以下异常并写入告警：

| 告警规则 | 说明 |
|----------|------|
| 非常用端口连接 | 目标端口不是 80/443/53/22/21/25/110/143/993/995 的连接 |
| 凌晨异常活动 | 00:00-06:00 期间单进程出站连接超过 50 次 |
| DNS 解析失败 | 查询结果为空的域名（可能是 DGA 域名） |
| 新域名告警 | 当天首次出现的域名（与历史日志对比） |
| 大文件下载 | 在 Downloads/Temp 目录创建的文件超过 100MB |
| 可疑进程名 | 进程名包含 miner、crypto、hack、inject 等关键词 |

## 六、脚本运行模式

脚本支持两种运行模式，通过参数区分：

```powershell
# 模式1：初始化（首次运行）
.\NetworkMonitor.ps1 -Mode Init

# 模式2：每日归集（任务计划调用）
.\NetworkMonitor.ps1 -Mode Export

# 模式3：立即归集（手动触发，不限时间范围）
.\NetworkMonitor.ps1 -Mode Export -Hours 48    # 归集过去48小时

# 模式4：查看状态
.\NetworkMonitor.ps1 -Mode Status
# 输出：
#   Sysmon 服务状态：运行中
#   审计策略状态：已开启
#   DNS日志状态：已开启
#   任务计划状态：已注册
#   日志目录：D:\NetworkMonitor\logs
#   已有日志：87 个文件，共 1.2 GB
#   最早日志：2026-04-28
#   最新日志：2026-07-27
```
